# پرش خطرناک | Danger Jump

> دونده‌ی بی‌پایان ۲بعدی روی پشت‌بام‌های تهران — **یه پرش اشتباه، پایان بازی!**

بازی آرکید «یک‌لمسی» ساخته‌شده با **Godot 4.3** و **GDScript** که کاملاً آفلاین روی اندروید اجرا می‌شود. کاراکتر خودش می‌دود و شما فقط یک کار دارید: **درست و به‌موقع بپرید!**

---

## معرفی

«پرش خطرناک» یک بازی فرار (Endless Runner) با حال‌وهوای ایرانی است. کاراکتر ما «پرشو» روی پشت‌بام‌های قدیمی تهران می‌دود؛ از روی تیغ‌ها، کولرهای آبی و حفره‌های بین پشت‌بام‌ها می‌پرد و هرچه جلوتر برود، سرعت و سختی بیشتر می‌شود. نسخه‌ی فعلی یک نسخه‌ی «کوچک اما کامل» است: منوی اصلی، گیم‌پلی کامل، توقف، پایان بازی، شروع مجدد، امتیاز و ذخیره‌ی رکورد — همه کارا و بدون خطا.

## ویژگی‌های نسخه ۱.۰.۰

- **پرش تک‌لمسی:** لمس صفحه / کلیک ماوس / کلید Space — پرش دوم در هوا عمداً قفل است.
- **۴ نوع مانع:** تیغ زمینی، حفره بین پشت‌بام‌ها، کولر آبی (مانع بلند) و تیغ دوقلو.
- **تولید مسیر عادلانه:** قطعات از پیش طراحی‌شده با SegmentManager؛ عرض حفره‌ها و فاصله‌ی موانع دوقلو همیشه با «حداکثر مسافت پرش» سازگار است و دو چالش خطرناک پشت‌سرهم نمی‌آید.
- **سختی تدریجی:** سرعت از ۳۴۰ به سقف ۶۴۰ پیکسل‌برثانیه می‌رسد؛ همه‌ی اعداد قابل تنظیم‌اند.
- **امتیاز واقعی:** بر اساس مسافت (هر متر ۱۰ امتیاز) + ۵۰ امتیاز برای هر مانع عبوری.
- **ذخیره‌سازی مقاوم:** رکورد و تنظیمات با ConfigFile در `user://` ذخیره می‌شود؛ فایل خراب خودکار به پیش‌فرض برمی‌گردد.
- **رابط کاربری کاملاً فارسی و راست‌به‌چپ** با فونت وزیرمتن.
- **توقف واقعی:** در حالت توقف، حرکت، تولید مسیر و امتیازدهی کاملاً منجمد می‌شود.
- **شروع مجدد کامل:** سرعت، امتیاز، موانع، وضعیت کاراکتر و تایمرها همه از صفر.
- **جلوه‌ها:** پارالاکس چندلایه (آسمان گرگ‌ومیش، گنبدها و مناره‌ها، پشت‌بام‌های همسایه)، انیمیشن دویدن/پرش/فرود، ذرات گرد‌وخاک، سایه‌ی ارتفاع‌سنج، شال‌گردن مواج و لرزش کوتاه دوربین هنگام برخورد.
- **صدا:** پرش، فرود، عبور از مانع، برخورد، پایان بازی، رکورد جدید و دکمه + موسیقی پس‌زمینه؛ همگی از تنظیمات قابل قطع و تنظیم‌اند.
- **بدون هیچ مجوز اندرویدی:** کاملاً آفلاین، بدون تبلیغات و سرویس خارجی.

## پیش‌نیازها

- [Godot 4.3](https://godotengine.org/download) یا جدیدتر (نسخه‌ی استاندارد، بدون .NET)

## اجرا

### دسکتاپ
1. پروژه را Clone یا Download کنید.
2. در Godot، دکمه‌ی **Import** را بزنید و پوشه‌ی پروژه (فایل `project.godot`) را انتخاب کنید.
3. **F5** — بازی اجرا می‌شود.

### اندروید (تست سریع بدون نصب)
- در Godot از منوی Project › Export دستورالعمل بخش «خروجی اندروید» همین فایل را ببینید.

## تنظیمات گیم‌پلی (در `scripts/game_manager.gd`)

| پارامتر | مقدار پیش‌فرض | توضیح |
|---|---|---|
| `initial_speed` | ۳۴۰ | سرعت اولیه‌ی دویدن (px/s) |
| `max_speed` | ۶۴۰ | سقف سرعت |
| `acceleration` | ۷٫۵ | افزایش سرعت در هر ثانیه |
| `jump_velocity` | ‎-۹۵۰ | نیروی پرش (ارتفاع ≈ ۱۸۸ پیکسل) |
| `jump_gravity` | ۲۴۰۰ | جاذبه‌ی پرش (زمان پرواز ≈ ۰٫۷۹ ثانیه) |
| `kill_y` | ۸۶۰ | عمق سقوط به حفره = مرگ |

فرمول‌های عدالت مسیر: عرض حفره = `clamp(سرعت × ۰٫۴۶, ۱۵۰, ۳۴۰)` و فاصله‌ی تیغ دوقلو = `clamp(سرعت × ۰٫۳۰, ۱۲۰, ۲۲۰)` — هر دو از «حداکثر مسافت پرش» با حاشیه‌ی امن حدود ۳۵٪ کوچک‌ترند.

## Seed مسیر

هر دور با یک Seed تصادفی ساخته می‌شود که در کنسول چاپ می‌شود (`[SegmentManager] seed = ...`). برای تکرار دقیق یک مسیر (مثلاً برای دیباگ)، در صحنه‌ی gameplay نود `World/SegmentManager` را انتخاب و در فیلد `Fixed Seed` مقدار بگذارید؛ یا در کد `GameManager.run_seed` را ثابت کنید.

## خروجی اندروید (APK)

1. **Java JDK 17** را نصب کنید.
2. **Android Studio** را نصب و از SDK Manager موارد زیر را بگیرید: Android SDK Platform 34، SDK Build-Tools، Platform-Tools و **Command-line Tools**.
3. در Godot: `Editor > Editor Settings > Export > Android` مسیرهای Android SDK و JDK را تنظیم و **Install Android Build Template** را بزنید (اگر Godot نتوانست نصب کند، دکمه‌ی مربوطه را از منوی Project › Install Android Build Template اجرا کنید).
4. یک Keystore بسازید (برای نسخه‌ی نهایی):
   ```bash
   keytool -genkeypair -v -keystore danger-jump.keystore -alias dangerjump -keyalg RSA -keysize 2048 -validity 10000
   ```
5. منوی `Project > Export...` — پریست آماده‌ی **Android** از قبل موجود است؛ فقط خروجی را بگیرید (Debug APK برای تست نیازی به keystore ندارد).
6. فایل `build/DangerJump.apk` را به گوشی منتقل و نصب کنید.

> پریست از معماری‌های armeabi-v7a و arm64-v8a استفاده می‌کند و **هیچ مجوزی (Permission) از اندروید نمی‌خواهد**.
