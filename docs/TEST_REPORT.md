## روش تست

آزمون دود به‌صورت یک AutoLoad فعال می‌شود و همان مسیری را طی می‌کند که بازیکن واقعی طی می‌کند: منو → شروع → دویدن → پرش → مرگ → پایان → ری‌استارت. ورودی‌ها از طریق سیستم ورودی واقعی موتور (`Input.parse_input_event`) شبیه‌سازی می‌شوند تا زنجیره‌ی کامل لمس → سیگنال → فیزیک پوشش داده شود.

## چیزهایی که در این محیط تست نشد (شفاف‌سازی)

- **خروجی APK ساخته نشد:** در این محیط Android SDK / JDK / keystore موجود نیست؛ طبق توافق، به‌جای ادعای نادرست، `export_presets.cfg` آماده شد و مراحل دقیق در README آمده است. بقیه‌ی کار فقط نصب SDK و کلیک Export است.
- **لمس واقعی روی دستگاه فیزیکی:** تست لمس در این محیط شبیه‌سازی شده است؛ روی دستگاه واقعی حتماً یک دور «دویدن + پرش + توقف + ری‌استارت» را دستی هم امتحان کنید.
- **نرخ فریم ۶۰FPS روی گوشی میان‌رده:** هدف طراحی است (رندر GL Compatibility + شکل‌های ساده + حذف اشیای پشت دوربین) اما اندازه‌گیری واقعی نیاز به دستگاه دارد.
