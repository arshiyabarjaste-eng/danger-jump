# چک‌لیست ۱۴ موردی تست — پرش خطرناک

| # | مورد | روش آزمون | وضعیت |
|---|---|---|---|
| ۱ | اولین اجرای پروژه بدون خطا | ایمپورت headless + بوت ۳۰۰ فریم | PASS |
| ۲ | پرش با لمس / کلیک / Space | تست دود: `jump_works` | PASS |
| ۳ | پرش دوم در هوا ممنوع | تست دود: `no_double_jump` | PASS |
| ۴ | برخورد با تیغ = مرگ | تست دود: `hit_causes_death` | PASS |
| ۵ | سقوط در حفره = مرگ | منطق `kill_y` + اجرای واقعی مسیر | PASS |
| ۶ | ری‌استارت، همه‌چیز را کامل صفر می‌کند | تست دود: `restart_resets` | PASS |
| ۷ | امتیاز = مسافت + جایزه‌ی مانع | تست دود: `score_increases` + `score_recorded` | PASS |
| ۸ | ذخیره‌ی رکورد + مقاومت به فایل خراب | `submit_score` + مسیر خطای `load_data` | PASS |
| ۹ | توقف، حرکت/تولید/امتیاز را کامل منجمد می‌کند | تست دود: `pause_freezes` / `resume_works` | PASS |
| ۱۰ | دکمه‌های UI باعث پرش اشتباه نمی‌شوند | فیلتر ماوس دکمه‌ها + `first_tap_no_jump` | PASS |
| ۱۱ | حفره‌ها همیشه قابل عبورند | تست دود: `gap_fair` (فرمول + حاشیه ۳۵٪) | PASS |
| ۱۲ | تولید مسیر با Seed تکرارپذیر | چاپ seed در کنسول + اجرای دو باره با seed ثابت | PASS |
| ۱۳ | افکت‌های صوتی و قطع صدا از تنظیمات | تست دود: `audio_streams` + `settings_persist` | PASS |
| ۱۴ | رابط فارسی راست‌به‌چپ با فونت درست | RTL سراسری در `ui_theme.gd` + فونت وزیرمتن (بازبینی بصری روی دستگاه به عهده‌ی کاربر) | PASS* |

*مورد ۱۴ در محیط headless قابل دیدن نیست؛ کد اعمال RTL و فونت در همه‌ی صفحات اعمال شده و نیاز به یک نگاه بصری روی دستگاه دارد.
